# Document Management System

A full-stack web application for managing document workflows.

## Features
- Create documents
- Update document status (Draft, Review, Approved, Archived)
- Search and filter documents
- Dashboard statistics
- Color-coded workflow buttons

## Tech Stack
Frontend: React, Axios, CSS  
Backend: Node.js, Express  
Database: MongoDB Atlas  

## Deployment
Frontend: Vercel  
Backend: Render
